# Revisão do catálogo (outubro de 2026)

Cada alteração feita em `js/dados.js` nesta revisão, com o motivo. Para desfazer uma alteração, edite o item no próprio app (a edição fica salva no navegador) ou peça a reversão.

Fontes: bulas ANVISA, MS (dengue, PCDT-IST, Guia de Vigilância), Beers 2023, NICE, IDSA, CHEST e MSD. Os itens clínicos passaram por verificação independente antes de entrar.
