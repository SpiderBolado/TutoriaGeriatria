Como usar o Gerador de Receitas

  1. Preencha o paciente. Digite o nome completo no campo "Paciente". Se for criança, informe o peso em kg — isso calcula automaticamente a dose de medicamentos com posologia por peso.
  2. Escolha o tipo de receita. "Comum (1 via)" para receitas normais, ou "Controle especial (2 vias)" para medicamentos controlados (sai em duas vias lado a lado, para farmácia e paciente).
  3. Busque e adicione condições/medicamentos. Use a busca à esquerda para encontrar uma condição clínica (adiciona todos os medicamentos daquela condição de uma vez) ou um medicamento específico. Clique para adicionar à receita.
  4. Ajuste se precisar. Na prévia da receita (painel direito), você pode editar a posologia de um item só para este paciente, ou remover itens clicando no "×".
  5. Preencha seus dados (nome e CRM). Antes de gerar a receita, preencha seu nome e CRM na seção de dados do médico — eles ficam salvos neste computador para as próximas receitas, mas cada profissional deve conferir/preencher os seus ao usar o app pela primeira vez neste dispositivo.
  6. Gere a receita. Use "Imprimir / PDF" para imprimir direto, ou "Baixar .docx" para gerar um arquivo Word editável.
  7. Atalhos úteis: tecla "/" foca a busca; Enter na busca seleciona o primeiro resultado; teclas 1–9 aplicam as condições mais usadas; Ctrl+Enter limpa a receita para o próximo paciente.

Todos os dados (histórico, medicamentos personalizados, nome/CRM) ficam salvos apenas neste computador/navegador — nada é enviado para a internet. Use "Exportar backup" periodicamente para não perder suas personalizações.

⚠ Informe o peso — 1 ou mais itens selecionados calculam a dose por kg
